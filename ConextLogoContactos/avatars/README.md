# conext — avatares por defecto

12 fantasmas para contactos sin foto. Reemplazan el ícono gris de persona.

- `ghost-a` … `ghost-l` — SVG (cualquier tamaño) + PNG 256px
- `avatar.js` — `ghostFor(phone)` devuelve siempre el mismo fantasma para el mismo contacto

Cada uno ya viene recortado en círculo, así que no hace falta `border-radius`.
